Real bugs fixed.

5 / 5

These were broken across the live demos — the kind of things a prospective client would notice in the first minute and quietly close the tab.

Bug · Highest impact

Filter tabs now actually filter.

Every category page advertised filters (Diamond, Pottery, Commercial, Bridal…) but clicking them only toggled the active class — never hid a card. Fixed with proper data-cat matching, sibling-scoped, with full keyboard tab-list ARIA.

  • demo.js
  • boutique/collections.html
Bug · Unstyled UI

The .filter-btn class was unstyled everywhere.

Three of four listing pages used .filter-btn, but the CSS only defined .filter-tab. Result: default browser buttons on jewellery, ecommerce, realestate. Aliased so both classes render identically.

  • demo.css
Bug · Silent CSS failure

Yoga schedule referenced undefined CSS variables.

The table used --fg-2 / --fg-3 / --fg-4 / --font-mono — none exist. Browser fell back to currentColor, killing the entire visual hierarchy. Remapped to the real tokens.

  • yoga/classes.html
Bug · Dead component

Breadcrumb defined but never used.

Styles for .breadcrumb sat in demo.css with zero instances on any sub-page. Now rendered on every upgraded sub-page above the H1.

  • 7 sub-pages
Bug · Low contrast

Body copy was reading as a label.

Core descriptions (menu items, services, product categories) all used --text-3 (#8A8578 on near-black) — barely WCAG AA. Bumped to --text-2. --text-3 now reserved for labels/meta only.

  • demo.css
A11y

No focus indicators anywhere.

Keyboard users had no idea where focus was. Added a single global :focus-visible rule with accent-coloured ring, plus arrow-key navigation for filter tabs and Esc-to-close mobile nav.

  • demo.css
  • demo.js

New shared components.

8 modules

Drop-in additions to demo.css + demo.js. Reusable across all 8 category demos and ready to ship with new client builds.

Local bar

Sticky open-now + hours strip.

Live-pulse dot, hours, address, phone, WhatsApp. Auto-detects open/closed from a data-hours attribute (handles multi-window like 9–1 + 5–8 PM). Sticks below the nav.

Jump nav

Sticky section pills with scroll-spy.

Horizontal scrolling pill row that tracks active section on scroll. Smooth-scrolls with nav offset compensation. Used on long pages — restaurant menu, healthcare services, yoga classes.

Header chips

Contextual metadata in the page header.

Solves the "empty page-header" problem. Each sub-page now shows what matters — counts, gold rate, today's hours, free-consultation chip — instead of just a title.

Trust strip

BIS / IGI / shipping / returns row.

5-chip horizontal strip for trust signals. Critical for jewellery and ecommerce; designed to drop above the footer on any page that needs to close the deal.

Listing toolbar

Live count + sort dropdown.

"6 of 6 products" updates as filters apply. Sort by price asc/desc/name reorders the grid in place. Targets any grid via data-target selector.

FSSAI veg mark

Canonical Indian veg/non-veg square.

The green-square-in-square / red-square-in-square every Indian diner recognises. Replaces the generic "Veg" pill on the restaurant menu.

Row action

Inline book / ask CTA per row.

Tiny outline-pill action on every service row, menu item, and class card. Closes the gap between "I'm interested" and "I'm scrolling to the bottom CTA".

Schema.org

Structured data for local SEO.

Restaurant, MedicalBusiness, with opening hours, address, rating, specialties. Free Google rich-result eligibility on every client launch.

What's next.

Things I flagged in the review but didn't ship in this pass — flagged here so you can decide what's worth a second round.

  • Replace SVG listing thumbs with real photography. The hand-drawn SVGs work great on the homepage hero but read as wireframes on listing grids. Single biggest "demo → real site" upgrade.
  • Per-item detail page or modal. Cards aren't clickable yet. Wrap each in an anchor + lightweight modal would add huge realism.
  • Schema for the remaining 6 categories. Salon (HairSalon), Yoga (LocalBusiness + Event for classes), Real estate (RealEstateListing), etc.
  • Sticky CTA buttons on mobile. The bottom WhatsApp float is good; a "Book / Visit / Order" anchor button next to it would close more.
  • Cookie consent + Razorpay/UPI logos. Required for real Indian launches; placeholders now, swap when live.
  • Phase 2 portal scaffolding. The PHASE2_ROADMAP.md plan is solid — Supabase auth + admin lead table is a 3-weekend project.
