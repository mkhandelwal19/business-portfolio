# Netloom logo pack

The mark and wordmark exactly as the site draws them: the woven N (two ivory
stems, a gold thread passing over the left stem and under the right) beside
"Netloom." in Manrope 800, tracked −0.04em, with the gold full stop. Lockup
proportions are the site nav's (mark 1.36em beside the type, 0.48em gap).

Colours: navy `#0A0F1E` · ivory `#F4EFE6` · gold `#C9A84C` · paper `#FBF8F3`.

| File | Use it for |
|---|---|
| `netloom-logo-horizontal-navy` | The default. Documents, decks, email headers, anywhere the navy tile can sit. |
| `netloom-logo-horizontal-for-dark-transparent` | Over photos or dark surfaces — ivory type, no background. |
| `netloom-logo-horizontal-paper` | Print and light layouts, on the warm paper tone. |
| `netloom-logo-horizontal-for-light-transparent` | Over white or light surfaces — navy type, no background. |
| `netloom-logo-stacked-*` | Square placements: social headers, watermarks, favicons that need the name. Same four variants. |
| `netloom-mark-tile` | App-icon style: the mark on a rounded navy square. WhatsApp Business, Meta Business Suite, favicons. |
| `netloom-mark-for-dark-transparent` / `-for-light-transparent` | The mark alone, no background. |
| `netloom-instagram-profile-1024` | Upload as the Instagram profile picture — sized so the circle crop keeps the whole mark. |

PNGs are 4× renders (horizontal ≈ 4100 px wide, marks 2048 px). SVGs are true
vectors with the wordmark outlined — no font needed — for print and signage.

Rules: never recolour the thread, never set the wordmark in another face, and
keep clear space of at least the mark's width around the lockup. Do not put
the ivory version on a light background or the navy version on a dark one —
there is a transparent file for each.
